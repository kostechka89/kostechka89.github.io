# Константин П. Р. — личная страница

React + Vite. Компоненты React Bits: Pattern Waves, Tech Text, Flex Carousel, Text Loop, Folder Float, Swipe Toast, Pulse Heart, Dodge Field, Logo Loop, Gooey Nav и Counter.

## Запуск

Node.js 22 и pnpm 11:

```sh
pnpm install
pnpm dev
pnpm build
```

GitHub Actions публикует `dist` в GitHub Pages при push в main. В Settings → Pages источник должен быть GitHub Actions.

## Контент

Тексты и ссылки: `src/main.jsx`. Оформление: `src/style.css`. Фотографии, локальные иконки бирж и резюме: `public/`.

Сведения составлены по материалам владельца, его прежнему резюме и публичным репозиториям. Репозиторий Aster обозначен как форк Pastfin, а не как полностью авторский проект. Работа ИП указана за 2024–2026: в публичной записи РБК указано прекращение деятельности 29.04.2026. Уровни владения языками, доходность трейдинга и результаты проектов не выдуманы.

Лайк сохраняется на устройстве посетителя. Визиты считаются по сессиям в этом браузере. Это не общая статистика сайта. Для общих счётчиков нужен отдельный сервис с хранилищем. Локальные счётчики не передают информацию на внешний сервер.

Изображения бирж — локально сохранённые иконки их доменов. Названия GoodCrew и SeaTester оформлены типографикой, без выдуманных фирменных знаков. Видео не добавлено: для галереи использованы семь предоставленных фотографий.
